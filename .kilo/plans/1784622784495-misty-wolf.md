# Plan · 片頭片尾精品化：程序化系統編排優化策略

> 2026-07-21 · mint misty-wolf  
> Scope: agent 邏輯深挖 → 成片片頭/片尾從「靜態補丁」升級為程序化精品序列。

---

## 1. 現況診斷（已實地巡檢）

| 層級 | 現況 | 問題 |
|------|------|------|
| **FFmpeg plate** | `render_final.py::mkcard_video` 產 dark-wine 漸層 + 單行標題/「完」 | 靜態 PNG loop；無層次、無 cast、無導語 |
| **HyperFrames** | `export_composition.py` 疊 `#title-card` / `#end-card` + GSAP fade-in | 只有字體動畫；無分段、無 credits roll、無視覺 motif |
| **Remotion** | `Film.tsx` 疊 titleFrames/endFrames | 同 HF；無滚动字幕、無 cast 卡 |
| **Schema** | `film-spec` 僅有 `title`、`end_title`(CLI)、`title_dur`/`end_dur` | 無結構化 credits、cast_roll、title_sequence 元數據 |
| **Dispatch** | `dispatch.py` 只路由到 media/voice/design 環 | 片頭片尾不是一等公民；無專門 action |

**核心痛點**：
1. 片尾是「完」一字，不是 credits roll → 無精品感。
2. 片頭只有標題 fade-in → 無情緒建立、無 logline、無 visual motif。
3. 設計後期雖可加動畫，但完全依賴 agent 手寫 HTML/React → 不可複製、無法程序化。
4. 現有 `director_intent`（logline / theme / visual_motifs / cast）**未被片頭片尾消費**。

---

## 2. 目標（精品定義）

- **片頭**：3–5 秒程序化標題序列，消費 `director_intent` + `sound_plan.mood`，包含：
  - 主標題 + 副標題（logline / theme）
  - 視覺 motif 詞雲/圖騰（如「雨=冷靜外壳」「後視鏡=偷窺」）
  - 情緒色票 + 字體動畫（GSAP / React spring）
- **片尾**：滾動 credits（4–8 秒），消費 `director_intent.cast` + shot 分鏡 + crew placeholders：
  - Cast list（角色名 → 演員/身份標籤）
  - Shot inventory（如需要）
  - 製作鳴謝（可關閉）
- **程序化**：從 `film-spec.json` + `manifest.json` 自動生成，不依賴 agent 手寫。
- **雙引擎對稱**：HyperFrames HTML + Remotion React 同步產出。
- **硬門禁不鬆動**：plate-cards blank、subs off、byte-identical continue 縫、review-final 七維。

---

## 3. 系統策略（四根支柱）

### 3.1 Metadata-first：Schema 擴充（向後兼容）

在 `film-spec.schema.json` 頂層加 **可選** 物件：

```json
"title_sequence": {
  "type": "object",
  "properties": {
    "subtitle": { "type": "string" },
    "tagline": { "type": "string" },
    "show_motifs": { "type": "boolean", "default": true },
    "style": { "enum": ["auto", "cinematic", "noir", "playful", "ecchi-rnb", "minimal"] }
  },
  "additionalProperties": true
},
"end_roll": {
  "type": "object",
  "properties": {
    "mode": { "enum": ["auto", "full", "cast_only", "none"], "default": "auto" },
    "cast_heading": { "type": "string", "default": "Cast" },
    "crew_heading": { "type": "string", "default": "Crew" },
    "show_shot_list": { "type": "boolean", "default": false },
    "scroll_duration_sec": { "type": "number", "minimum": 2, "maximum": 12, "default": 5 }
  },
  "additionalProperties": true
}
```

**向后兼容**：`additionalProperties: true` + 所有欄位預設值；舊 spec 不寫也不影響現有流程。

### 3.2 Procedural Generator：設計後期橋接擴充

在 `export_composition.py` 內新增模組化函式：

```
export_composition.py
  ├── build_title_sequence_html(package, preset, styles)    → HF <section>
  ├── build_end_roll_html(package, end_roll, preset)       → HF <section>
  ├── build_title_sequence_tsx(package, preset)            → Remotion component
  ├── build_end_roll_tsx(package, end_roll)                → Remotion component
  └── derive_credits_from_spec(spec, manifest)             → 结构化 credits data
```

**HF 輸出範例**：
- 片頭：`<section id="title-sequence">` 內含多層 `div`（主標題、副標題、motif 標籤），由 GSAP timeline 依序入場。
- 片尾：`<section id="end-roll">` 內含 `.credits-track`，CSS animation `translateY` 模擬滾動；可選分節（Cast / Crew / Shots）。

**Remotion 輸出範例**：
- 新檔案 `src/TitleSequence.tsx`、`src/EndRoll.tsx`
- 使用 `interpolate` + `useCurrentFrame` 做 spring / scroll；保留 `Film.tsx` 作為主 compositional wrapper。

### 3.3 Style Preset 擴充

現有 `ecchi-rnb` / `minimal` 二檔，擴為：

| preset | 片頭風格 | 片尾風格 |
|--------|----------|----------|
| `auto` | 依 `sound_plan.mood` / `director_intent.tone` | 同上 |
| `cinematic` | 黑金、寬字距、logo 占位、logline 打字機 | 金字滾動、Cast 分欄 |
| `noir` | 高对比黑白、陰影遮罩、單線條 | 白字黑底、極簡滚动 |
| `playful` | 彈性縮放、彩色 motif 標籤、手寫體 | 彩色圓點 + cast 名 |
| `ecchi-rnb` | 玫瑰疊層、 blush 字幕條（現有） | 暖色半透明 cast 卡 |
| `minimal` | 乾淨黑底、細邊（現有） | 細字滾動、無裝飾 |

實作：`preset_hf_styles()` / `preset_remotion_styles()` 返回完整 style dict（顏色、字體、動畫曲線、陰影）。

### 3.4 Dispatch 一體化

在 `dispatch.py` 的 `post` 環加入：

```python
if craft_stage == "post":
    pre("design-title-sequence", 'aifilm export-compose --title-sequence auto ...', ...)
    pre("design-end-roll", 'aifilm export-compose --end-roll auto ...', ...)
```

或在 `final --post-engine hyperframes` 內自動觸發（不改變現有 CLI 預設行為）。

## 4. 實作階段（建議 3 個迭代）

### Phase 1 · Metadata + Derivation（1 週）
- **Schema**：`film-spec.schema.json` 加 `title_sequence` / `end_roll`；`write-spec` 自動填入預設（不破壞現有 spec）。
- **Derivation**：`derive_credits_from_spec(spec, manifest)` 從 `director_intent.cast` + `scenes[].shots[]` 自動產出 cast/shots/crew 列表。
- **Tests**：schema validation 單元測試；derivation 從 minimal spec 生出非空 credits。

### Phase 2 · HyperFrames Engine（1 週）
- **HF HTML**：`build_title_sequence_html()` / `build_end_roll_html()` 寫入 `compose/hyperframes/index.html`。
- **Styles**：6 档 preset style dict + GSAP timeline 生成。
- **Plate coordination**：確保 `plate-cards blank` 仍留 `title_dur` / `end_dur` pad；HF overlay 與 plate 時鐘對齊。
- **Tests**：`test_export_composition.py` 加 title-sequence/end-roll 斷言；`test_title_double_burn_docs.py` 維持通過。

### Phase 3 · Remotion + Dispatch + Polish（1 週）
- **Remotion**：`TitleSequence.tsx` / `EndRoll.tsx`；`Film.tsx` 條件渲染。
- **Dispatch**：`dispatch.py` post 環路由 + `next_actions.py` 建議 `--title-sequence` / `--end-roll`。
- **CLI**：`aifilm final` / `export-compose` / `compose-render` 暴露 `--title-sequence` / `--end-roll` / `--title-preset`。
- **Integration tests**：end-to-end export-compose + compose-render smoke test。

## 5. 硬門禁與約束（不可妥協）

| 約束 | 對應現有紀律 | 新實作中的守護 |
|------|-------------|---------------|
| **標題雙燒** | `plate-cards blank` + `subs off` | 新 title/end roll 只在 HF/Remotion overlay；plate 永遠 blank |
| **Byte-identical continue** | `hard match-cut` on continue 縫 | title/end 在 underlay 前後；不碰 clip-to-clip 縫 |
| **七維審批** | `review-final` | 動態片頭片尾不減少任何維度；增加 `title_design` / `end_design` 觀察項 |
| **安全/效能** | `security_policy` + `minimal_subprocess_env` | 新函式只用標準庫 + PIL + FFmpeg；不引入新外部依賴 |
| **可恢復性** | receipts + manifest | 寫入 `receipts/title-sequence.json` / `receipts/end-roll.json`（設計意圖、使用 preset、 generated_at） |

---

## 6. 驗收條件

1. **舊 spec 無痛升級**：無 `title_sequence` / `end_roll` 欄位的 `film-spec.json` 跑 `final --post-engine hyperframes` 仍成功，且片頭片尾與現在行為一致（預設 minimal + 1.5s + 「完」）。
2. **新 spec 精品出片**：含 `title_sequence` / `end_roll` 的 spec 產出：
   - 片頭：≥2 層動畫元素（標題 + 副標題 或 motif），時長 2–5s。
   - 片尾：滚动 cast/crew 列表，時長 3–8s，不覆蓋最后一镜重要構圖。
3. **雙引擎對稱**：HyperFrames 與 Remotion 產出同構內容（HF HTML section / Remotion component）。
4. **門禁綠燈**：`doctor` + `preflight` + `review-final` 七維 pass + `test_title_double_burn_docs` pass。
5. **Agent 可調度**：`dispatch` 在 post 環能推薦 `--title-sequence auto` / `--end-roll auto`。

---

## 7. 風險與緩衝

| 風險 | 緩衝 |
|------|------|
| HyperFrames/Remotion 動畫在 underlay 上造成 performance 問題 | 限制片頭≤5s、片尾≤8s；CSS `will-change` 最小化；HF check 自動擋幀率過低 |
| 滾動字幕遮擋最后一镜臉部 | `end_roll` 起始位置自動計算（最後 20% 畫面下緣），可手動 `end_roll.show_shot_list=false` |
| 舊版 film-spec 缺 `director_intent.cast` | `derive_credits_from_spec` fallback 到空 list + 僅顯示 "A Film By [title]" |
| Agent 濫用自訂 preset | preset 枚舉在 schema 鎖定；auto 由現有 `resolve_compose_preset` 邏輯延伸 |
| 片頭片尾過長拖慢交付 | `title_dur` / `end_dur` 仍為硬上限；procedural generator 內部 clamp |
