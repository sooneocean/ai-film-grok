# Lesson 2026-07-21 · 资深蒙太奇剪辑 + 重口男向成人尺度

> **片例**：`velvet-stage-dual`（丝绒双姝）  
> **用户原话**：  
> - 「剪辑跟运镜还有动态太差劲了…希望像资深剪辑有各种蒙太奇技巧」  
> - 「剧情的尺度太小了…成人重口…面向重口的男性观众」  
> - 「请沉淀教训到 skill 让 skill 更强大」  
> **P 码**：P0 交付 · P3 动能 · P4 语义 · P5 分层 ·（叙事）看点/刺激点  

## 失败解剖（本片证据）

| 用户感受 | 工程事实 | 根因 |
|---|---|---|
| 剪辑差 | 10 镜近似 **顺序拼板**；`edit_craft` 几乎全是 `cut_on_action`/`fade` | 把 Editor’s Cut 当成「挑 10 镜 concat」，**没用 craft 菜单**（smash/insert/montage/contrast） |
| 运镜差 | 多镜 soft lean / hold / 慢推 | motion 主动词弱；`camera_axis` 未按高潮段加速；无「狠动词表」硬门 |
| 动态差 | 像姿势轮播 | 缺 insert 蒙太奇（指节/锁/汗/腿）；缺 action→reaction smash；continue 链未真正 mid_motion 硬切 |
| 尺度小 | 成片偏「舞台暧昧 + 软贴身」 | setup/台口占太多；act/climax 镜不够狠；VO 仍「文艺说书」未按**男向重口**写满；审核软化后未用 B 轨（VO/SFX/insert）补刺激 |

**抽象**：  
1. **库存齐 ≠ 剪辑完成** —— 资深剪辑是在库存上**重写节奏与冲击**。  
2. **heat_scale:max 写了 ≠ 观众感到重口** —— 必须用镜比 + VO 动词 + 蒙太奇把刺激顶满。  
3. **男向重口 brief** 是显式受众信号 → 触发更狠的默认（见下 R-M / R-H）。

## R-M · 资深剪辑 / 蒙太奇硬规则（Montage Editor）

### M0 一句话

**禁止「说书幻灯片」成片**：资深剪辑 = **景别跳变 + 动作中切 + 插入特写 + 砸切对比 + 声画 L/J**，不是 10×6s 顺序放完。

### M1 Editor’s Cut 必须写「蒙太奇设计」而不只 selects 列表

`receipts/editor-cut.md` **新增必填块**：

```markdown
## 蒙太奇设计（Montage Plan）
- 节奏图：慢→加速→峰值→释放（秒级）
- craft 串（n-1）：… 禁止全 cut_on_action
- 至少 N 个 insert_cut（物件/身体局部）
- 至少 1 个 smash_cut 在高潮前
- 至少 1 段 montage_jump（2–4 镜动作连打）
- 景别峰谷：…（禁 5 镜同 MCU）
```

| 成片镜数 | insert 最少 | smash 最少 | montage_jump 段 |
|---|---|---|---|
| 8–12（~60s） | **≥2** | **≥1** | **≥1 段（含 ≥2 缝）** |
| ≥14 | ≥3 | ≥2 | ≥2 段 |

不达标 → Editor Cut **Action/Picture fail**，禁宣称可交付。

### M2 craft 串禁止扁平

| 禁止 | 要求 |
|---|---|
| `edit_craft` 全是 `cut_on_action` 或全 soft | 至少 **4 种**不同 craft |
| 全片 soft dissolve 装丝滑 | continue 缝 **hard**；冲击 **smash**；细节 **insert** |
| 只调 transition_sec 装资深 | 必须改 **镜序/去镜/加 insert/re-I2V** |

**60s 重口推荐 craft 脊柱**（可改词，不可再全 flatten）：

```text
whip_soft → insert_cut → cut_on_action → smash_cut
→ montage_jump → montage_jump → insert_cut
→ cut_on_action → smash_cut → mood_hold
```

权威菜单：[editorial-craft.md](editorial-craft.md)。

### M3 运镜 / 动态（资深摄影 + 剪辑交界）

| 段 | camera_axis / motion 纪律 |
|---|---|
| setup | 可慢；但 **1 镜内 visible_change** 仍要明显 |
| foreplay | 景别收紧；至少 1 次 dolly_in 或 pan_with **跟动作** |
| **act** | **狠动词表必出**：snap / yank / sink / grind / lock / slam（选 1+）；禁 soft lean 当主句 |
| **climax** | 峰值加速；reaction 可 micro，但前一缝必须是 **主动作** |
| afterglow | 可 hold；禁再用高速 |

| 指标 | 闸 |
|---|---|
| hook/approach/action `motion_score` | **< 5 → 强制 re-I2V**（不得只 re-final） |
| 连续 3 镜 motion 同构（全 blink+breath） | soft fail `MOTION_MONOTONY` → 改轴/改动词 |
| 无 insert 的 60s 成人片 | Editor Picture fail |

I2V prompt 顺序：**狠主动词 → camera_axis → 微动**；禁口型说话。  
词表：[shot-motion.md](shot-motion.md) §1c。

### M4 蒙太奇类型（agent 必会选用）

| 类型 | 用法（成人 60s） |
|---|---|
| **metric / 节奏蒙太奇** | 峰值段 2–4 缝 hard 连切，镜长可短于 6s（trim in/out 或 多 insert） |
| **insert 蒙太奇** | 锁扣 / 指节攥布 / 膝锁 / 汗 / 门闩 — 高潮前加压 |
| **对比蒙太奇** | 台口权力 vs 包厢失序；双女主权力翻转用 contrast_cut |
| **平行** | 双女主：A 感官 insert ‖ B 反应 — **镜序交错**写进 selects，勿指望自动 |
| **匹配剪** | continue 字节 + mid_motion hard（已有） |

**禁止宣称**做了蒙太奇却 craft 全 fade。

## R-H · 重口男向成人尺度（Hardcore Male Audience）

### H0 受众信号（触发条件）

用户出现任一类 → 进入 **男向重口模式** `audience_profile: hardcore_male`：

- 「重口 / 成人重口 / 里番顶格 / 办事完成拉满」  
- 「面向男性 / 男向 / 重口男性观众」  
- 「尺度太小 / 不够色 / 要更黄」  

| 字段 | 值 |
|---|---|
| `heat_scale` | **必须 `max`**（禁止默默 medium） |
| `audience` / `director_intent.audience` | 写明重口男向 |
| `heat_arc_advise` | true |
| VO | 身体动词可说满：结合、顶、吃进、腿软、办完（仍 18+ 同意虚构） |

### H1 亲密核镜比（重口默认，可软 warn）

对 **~60s / 10 镜 selects**：

| phase | 最少镜 | 说明 |
|---|---|---|
| setup | **≤2** | 台口再短；勿 4 镜还在走台 |
| foreplay | ≥2 | 落锁 / 失序 / 贴身 |
| **act** | **≥4** | 骑跨、沉腰、锁腿、节奏 — **占比最高** |
| **climax** | **≥2** | 完成拍 + 失声/腿软（可双女各一） |
| afterglow | 1 | 钩子，禁说教 |

亲密核（foreplay+act+climax）**目标 ≥70%** 片长（重口男向）；setup>30% → Editor Story **escalation fail**。

### H2 双 KPI 顶格（看点 + 刺激点）

| KPI | 重口男向抓手（至少各占 3 项） |
|---|---|
| **看点** | 权力差（谁主导）、双女合演/争夺、落锁仪式、金句、身份符号（狐尾/金星扣） |
| **刺激点** | 服装失序、距离顶格、**办事主动作**、**完成反应**、感官（喘/热/湿/攥）、未完钩子 |

只满足看点 = **尺度失败**（用户会说「太小」）。

### H3 双轨防审核坍缩（更强调）

| 轨 | 重口要求 |
|---|---|
| A 画面 | 顶格 **suggestive 姿态**（跨坐/沉腰/锁腿/仰头失神）；避免硬核生殖器特写连撞；姿势要「一眼读得出在办事」 |
| B 声 | VO **荤满**；SFX 落锁/解扣/肉体节奏/喘；画面被软化时 **B 轨加重 + insert 补** |

禁止：审核一次 → 整片退回「牵手对视 + 文艺旁白」。

### H4 VO 词表（男向说书人 · 仍 ≤55 字/镜）

| 弱（禁止当重口主句） | 强（优先） |
|---|---|
| 灯暗了，加演开始 | 帘一开，今晚加演只服务你 |
| 距离变近了 | 腰贴上了，心跳在掌心爆 |
| 她靠着她 | 沉腰一下一下，把规矩干穿 |
| 结束了 | 腿软了还不够——下一场换你顶 |

色气 BGM 仍默认 **rnb**（非 horror 不用 dark）。

### H5 Selects 优先级（Editor 从 20 库存剪 60s）

**优先保留**：latch / 失序 / 跨坐 / 沉腰 / 高潮反应 / 双人贴身  
**优先丢掉或压到 ≤1**：空舞台、纯台口走秀、无身体变化的近景对视  
用户要重口时：**禁止** selects 里 setup≥3 而 act+climax≤3。

## Agent 执行清单（成片前）

```text
1. 读 brief → 若重口男向 → audience_profile=hardcore_male + heat_scale=max
2. write-spec 后检查 _heat_arc 亲密核占比建议
3. bulk 时 act/climax still 姿态狠 + Hair lock + 零工程字
4. inventory 齐 → Editor’s Cut：
   a. 蒙太奇设计块（M1）
   b. craft 串 ≥4 种（M2）
   c. 重口镜比（H1）
   d. 弱 motion re-I2V（M3）
5. tts-rehearse（荤 VO）→ final(slot + craft) → 抽帧验无 shot 水印
6. review：escalation 必须 pass（刺激点到顶）
```

## 反例 / 正例

| 反例 | 正例 |
|---|---|
| 10 镜顺序：台口×3 → 抱抱×4 → 耳语×3 | 台口×1 → 落锁 → insert 扣 → smash 跨坐 → montage 沉腰×3 → climax×2 → 钩子 |
| edit_craft 全 cut_on_action | whip → insert → smash → montage×2 → insert → mood_hold |
| VO「加演开始」 | VO「沉腰把加演干成真的」 |
| motion soft lean + breath | motion hips sink hard twice, grip white knuckles, continuous |
