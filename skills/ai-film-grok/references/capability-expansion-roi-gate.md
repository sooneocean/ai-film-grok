# 能力扩展 ROI 闸门

> 目的：先提高现有成片流程的产量、质量与可核算性，再扩大模型和适配器面积。

## 默认冻结

新模型、新供应商、新适配器或新自动化接通后，只能标记为 `research` 或
`pilot_only`。在满足晋升条件前，禁止设为默认、禁止进入无人值守 bulk，也不得
用“安装成功、doctor 通过、生成过一个文件”代替生产证据。

## 晋升条件

候选能力必须同时满足：

1. 至少 **3 个**完整项目生成当前 schema 的 `optimization-metrics.json`；
2. 主比较指标的 `data_quality` 不得为 `invalid` 或 `partial`，成本、重试、
   人工分钟不得用推测值或假零补齐；
3. 与现行默认在相同质量门槛下比较，明确报告人时、一次通过率、重做率、成本
   和终端交付成功率；
4. pilot 由用户人工批准，许可、生产资格、凭据边界与预算状态均已验证；
5. 晋升后仍保留回退路径、来源 receipt 与媒体 read-back。

任何一项缺失，结论只能是“证据不足，继续 research”，不能静默晋升。

## 评估顺序

先修复可观测性和现有瓶颈，再比较候选能力；只有候选在真实项目上带来可复现的
净收益，才进入默认路线。单次 demo 的画质提升不能抵销不可核算的人工成本、
失败重做或授权风险。
