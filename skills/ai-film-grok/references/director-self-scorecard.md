# 导演自评卡（Director's Self-Scorecard）

> 2026-07-22 · 七维 review-final 是工程门禁（技术能不能发布）；
> 本卡是**导演自评**（成片有没有达到创作意图）。
> 两者不可互替：技术全 pass 的成片可能是「精致的废话」。

## 何时填

- `review-final` 七维通过后、`export-desktop` 前
- 或 `rough` 阶段做完 Editor's Cut 后自检

## 评分

每项 1–5 分 + 一句证据（不是打勾，是说服自己）。

### 1 · 节奏（Pacing）

**问**：观众在任何一秒会想划走吗？

| 分 | 标准 |
|----|------|
| 1 | 多处 dead air，镜间无能量传递 |
| 3 | 整体顺，但有 1–2 处拖 |
| 5 | 每秒都在推进信息或情绪，无废镜 |

证据要求：指出最可能划走的秒数段。

### 2 · 留白（Negative Space / Breathing）

**问**：有没有该停没停的地方？有没有不该停却停了？

| 分 | 标准 |
|----|------|
| 1 | 要么全程塞满，要么全程拖 |
| 3 | 知道该留白但时机不准 |
| 5 | 高潮前有呼吸，落点有余韵 |

### 3 · 情绪落点（Emotional Landing）

**问**：观众看完该有什么感觉？实际看完是什么感觉？

| 分 | 标准 |
|----|------|
| 1 | 看完无感或感觉散 |
| 3 | 有感觉但说不清为什么 |
| 5 | 情绪弧线清晰，落点与 director_intent.emotional_arc 吻合 |

证据要求：对照 `emotional_arc` 逐节点确认是否落到。

### 4 · 受众完成率假设（Completion Hypothesis）

**问**：目标受众会看到最后吗？钩子在前 3 秒吗？

| 分 | 标准 |
|----|------|
| 1 | 钩子弱或缺失，3 秒内无抓点 |
| 3 | 钩子有但中段掉人 |
| 5 | 钩子强 + 中段维持 + 结尾有余韵/反转钩 |

### 5 · 表演意图达成（Performance Intent）

**问**：角色的内在变化外化了吗？还是只有运动没有表演？

| 分 | 标准 |
|----|------|
| 1 | 角色能动但不知在想什么 |
| 3 | 部分镜头有 subtext，部分空 |
| 5 | 每镜角色内在 A→B 可指认 |

> 注：此维依赖新增的 `dsl.subtext` / `playable_action` / `body_state` 字段。
> 缺表演意图的镜在 write-spec 的 `_performance_lint` 里会 warn。

### 6 · 覆盖完整度（Coverage Integrity）

**问**：每镜都在证明一个 beat 吗？有没有「漂亮但无功能」的镜？

| 分 | 标准 |
|----|------|
| 1 | 有 ≥2 镜是装饰性，不推进 |
| 3 | 基本都有功能，1 镑可疑 |
| 5 | 每镜 dramatic_function + visible_change 都成立 |

### 7 · 转场修辞（Transition Rhetoric）

**问**：剪接本身在说话吗？还是只是「接上」？

| 分 | 标准 |
|----|------|
| 1 | 全 dissolve 或全硬切，无修辞意图 |
| 3 | 有 1–2 处有意图的转场 |
| 5 | 转场服务于情绪弧线（smash on turn / hold on afterglow） |

## 总分解读

| 范围 | 含义 |
|------|------|
| 7–18 | 还没到成片标准，回 Editor's Cut 或 re-craft |
| 19–28 | 技术合格，创作待打磨——可交付但留遗憾 |
| 29–35 | 导演满意——可发布 |
