## 失败解剖：为什么「已经 max」还是不够冲击

| 用户感受 | 工程事实 | 根因 |
|---|---|---|
| 尺度还是太小 | 有跨坐 / 贴身 / 高潮脸 | **跨坐≠在办事**：骨盆无咬合、节奏无起伏、衣着完整=姿势日历 |
| 想要性交画面 | heat max + 荤 VO | **画面仍在「暧昧拥抱」层**；VO 在说干，still 在说抱 |
| 冲击力不够 | 景别有堆叠 | **缺少性交六拍**（入口→结合→节奏→锁紧→完成→余颤） |
| 想要标竿 | 单片修好 | skill **无「静音一帧测试」**，agent 无法自证冲击 |

**抽象一句话**：  
观众感到冲击 = **静帧可读出「正在性交」** + **动态可读出「节奏」** + **景别越剪越近** + **声轨同动词**。  
少任何一环 = 看起来像色气舞台剧，不是成人漫剧标竿。

## R-X · 性交语法（Coitus Grammar）——标竿硬核

### X0 一句话

**成人漫剧标竿 ≠ 更露的脸红**；= 画面上有一条**可验收的性交因果链**：  
入口（谁进谁）→ 结合（骨盆咬合）→ 节奏（沉/顶/磨可见）→ 锁紧 → 完成反应 → 未完钩子。

### X1 静音一帧测试（Mute Frame Test）——**唯一冲击力 KPI**

对 **act + climax** 的任意 selects 关键帧（keyframe 或 clip t=1s）：

| 问题 | 必须答案 |
|---|---|
| 关掉声音，只看这一帧：**两人是否正在发生性交/结合？** | **YES**（含 yuri 骑跨结合、穿透暗示、明确骨盆咬合） |
| 只是拥抱 / 坐腿上 / 贴脸 / 牵手？ | **NO → fail `COITUS_UNREADABLE`** |

**禁止**用下列冒充性交画面：

| 伪性交（fail） | 真性交可读（pass） |
|---|---|
| 双人站立拥抱 | 骑跨且 **髋贴髋**、裙/裤 **掀开或偏开** |
| 并排坐沙发对视 | 一方 **仰倒**、一方 **覆上/跨上**，体重压实 |
| 只解外套肩带 | 下身/腰腹 **接触面可见**（大腿内侧、髋线、绷紧腹肌） |
| 只 CU 湿眼 | 先有 **节奏主动作镜**，再给完成脸 |
| 全装正襟危坐「跨坐」 | 衣着 **失序到办事层**（裙掀、扣解、手套抓肉） |

### X2 性交六拍（60s 标竿必见）

| 拍 | 代号 | 必须看见 | 景别建议 | 禁冒充 |
|---|---|---|---|---|
| 1 | **ENTRY** | 谁把谁压/拽/按到位（入口权力） | L1–L2 | 只牵手 |
| 2 | **UNION** | **骨盆咬合 / 跨坐落稳 / 结合瞬间** | L1–L2 | 空中悬腿假骑 |
| 3 | **RHYTHM** | **沉腰/顶撞/磨** 至少 2 次可见起伏 | L2 + L4 insert | soft lean 当主句 |
| 4 | **LOCK** | 腿锁腰 / 手抓床单 / 尾缠腕 | L3–L4 | 只眨眼 |
| 5 | **FINISH** | 办完：失声、拱背、腿软、攥白 | L3 | 只微笑 |
| 6 | **HOOK** | 「下一场换你」未完 | L3 | 说教晚安 |

**镜数配额（~10 镜 selects · hardcore_male）**：

| 拍 | 最少 |
|---|---|
| ENTRY+UNION | ≥2 |
| RHYTHM | ≥2（可 montage 连切） |
| LOCK insert | ≥1 |
| FINISH | ≥2（双女主可各 1） |
| HOOK | 1 |

亲密核（foreplay+act+climax）仍 **≥70%**；本课额外要求 act 段 **≥50% 静帧过 Mute Frame Test**。

### X3 冲击力最大化七刀（Impact Maximizers）

| # | 刀法 | 做法 | 为什么猛 |
|---|---|---|---|
| 1 | **骨盆可读** | 髋线、大腿夹角、体重下压画进 still | 一眼=在干，不是在抱 |
| 2 | **衣着办事层** | 裙掀/扣尽/手套抓肉/肩带崩；**禁止全装正装跨坐当 act 主镜** | 失序=刺激点 |
| 3 | **景别单向下压** | act→climax：**禁止**突然回全景再演办事 | 压迫感=冲击 |
| 4 | **节奏蒙太奇** | RHYTHM 段 2–4 缝 hard；insert 插 **腰/指/膝** | 时间压缩=猛 |
| 5 | **动静反差** | 慢入口 → 快节奏 → 突然静（FINISH hold） | 静比动更炸 |
| 6 | **声画同动词** | VO「沉腰/吃进/办穿」= motion 同词 | 假重口必死 |
| 7 | **双轨抗审核** | A 姿态顶格 suggestive；B 荤 VO+SFX 节奏；画面被软 → **加重 B + 加 insert**，禁整片退回拥抱 | 审核≠放弃标竿 |

### X4 姿态词表（still / I2V 优先 · 18+ 同意虚构）

**主动词（act 主句必须命中 ≥1）**：

```text
straddle-seat  ·  hips-sink  ·  grind-forward  ·  mount-settle
pelvis-lock    ·  leg-wrap-waist  ·  thrust-rhythm  ·  clutch-fabric
arch-finish    ·  residual-tremor
```

**禁止当 act 主句**：`soft lean` · `gentle hug` · `eye contact only` · `shoulder touch` · `sit beside`

**构图（冲击优先）**：

| 要 | 不要 |
|---|---|
| 侧 3/4 或正前可读夹腿角 | 遮死接触面的背后大空镜 |
| 腰+腿同框（L2） | 只给头肩装办事 |
| 抓肉/攥布的手（L4） | 悬空摆拍手 |
| 完成脸在 RHYTHM 之后 | 全程只湿眼无主动作 |

### X5 运镜 × 性交拍

| 拍 | camera_axis | motion 主句 |
|---|---|---|
| ENTRY | dolly_in / pan_with | push / seat / pin |
| UNION | locked 或 slight push-stop | settle hips · weight drop |
| RHYTHM | locked 或 low-angle lean-stop | **hips sink twice** · grind |
| LOCK | ecu_hold / static | squeeze · clutch · micro-tremor |
| FINISH | static_hold | arch → soften · wet eyes |
| HOOK | gentle pull-back hold | whisper lean · ear twitch |

L3/L4：**禁**大 orbit 晃脸；L4 仍遵守禁 fill-frame 裁头（物件/肢体优先）。

### X6 审核软化时的「标竿不降级」协议

Grok I2V / still 若拦硬核生殖器特写：

1. **不**把整片改成牵手文艺  
2. still 改用 **顶格 suggestive 结合姿态**（骑跨咬合 + 衣失序 + 表情）  
3. motion 保留 **hips sink / grind** 可过词  
4. **B 轨拉满**：VO 身体动词 + SFX 肉体节奏/喘  
5. 加 L4 insert（攥布/腿锁/门闩）补刺激  
6. receipts 记 `moderation_soften: true` + 双轨补偿清单  

禁止：一次 403 → `heat_scale` 默默降到 medium。
